# Task Observer

## Мета
Збирати спостереження за сесією, класифікувати їх і пропонувати конкретні
поліпшення: новий скіл, оновлення існуючого скілу, псевдонім команди,
або запис у пам’ять.

## Процес
1. Підсумуй, над чим працював користувач у цій сесії.
2. Виділи повторювані дії, помилки або питання.
3. Запропонуй 1–3 конкретні покращення.
4. Якщо користувач погоджується — створи або онови відповідний скіл.
